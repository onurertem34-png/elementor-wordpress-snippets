# Elementor & WordPress Snippets

A small collection of practical, copy-paste snippets and checklists for WordPress + Elementor sites, put together by [Onur Freelance](https://onurfreelance.com) - a web design and digital marketing agency based in Maltepe, Istanbul.

## What's in here

- `elementor-css-snippets.md` - CSS snippets for common Elementor customizations (sticky headers, hover effects, responsive spacing, custom buttons) that aren't exposed in the default Elementor UI.
- `wordpress-security-speed-checklist.md` - A practical checklist used when auditing WordPress sites for small businesses: security hardening basics and quick performance wins.

## Why

Most of this is scattered across forum posts and old blog comments. This repo collects the snippets we actually reuse on client projects into one place.
